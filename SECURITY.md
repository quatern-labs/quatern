# Security Policy

## Reporting a vulnerability

Please report security vulnerabilities privately by emailing **security@quatern.co**. Don't open a public issue.

Include:

- The Quatern version (`quatern --version`)
- Steps to reproduce
- The impact you observed or expect

We'll acknowledge your report within a few business days. Please don't disclose the issue publicly until it's fixed.

**Never include API keys, tokens, or other credentials in your report.**

## Scope

- The `quatern` CLI
- api.quatern.co
- quatern.co
